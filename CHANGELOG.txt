[2026-05-27] 严格 VAD + Whisper 解码优化 + 声纹验证拦截器

----------------------------------------



问题描述:

  1. Whisper 幻觉率过高: 环境音/静音也输出乱码 ("召开网络的评论", "诶诶诶...")

  2. 声纹只有注册功能，没有验证拦截: 注册后执行敏感指令无需身份验证



修改文件及内容:



  [1] audio/audio_preprocess.py

      - 新增 strict_vad() 严格端点检测算法:

        帧级能量分析: 计算每帧 RMS 能量

        噪声底估计: 取最安静 15% 帧的平均能量

        信噪比计算: 最响 20% 帧 / 噪声底, 转换为 dB

        语音比例: 超过能量阈值的帧占比

        拒绝条件 (任一满足即丢弃, 不传入 Whisper):

          - RMS < energy_threshold * 0.5 (太安静)

          - SNR < 6.0 dB (信噪比太低, 噪声主导)

          - 语音帧比例 < 20% (大部分是静音)

          - 语音时长 < 0.5s (有效语音太短)

        返回: (is_valid, speech_audio, meta) 三元组



  [2] asr/speech_recognizer.py

      - Whisper 解码参数优化 (反幻觉):

        no_speech_threshold=0.6 (提高无语音判断灵敏度)

        condition_on_previous_text=False (防止上下文污染)

        compression_ratio_threshold=2.4 (过滤重复压缩输出)

        log_prob_threshold=-1.0 (过滤低置信度输出)

        suppress_blank=True, suppress_tokens=[-1]

      - HOTWORDS 精简为 "以下是普通话的句子。"



  [3] controller/verification_gate.py (新文件)

      - PROTECTED_COMMANDS 受保护指令集合:

        open_app, close_app, shutdown, restart, logout, sleep,

        empty_recycle, delete_file, clean_temp,

        open_settings, open_task_manager

      - is_protected(cmd): 判断指令是否需要验证

        支持 "intent:param" 格式

      - verify_and_execute(): 验证拦截执行函数

        非受保护指令 -> 直接执行

        无注册用户 -> 跳过验证, 直接执行

        受保护指令 -> 提取声纹特征 -> verify_any_user() ->

          相似度 >= 0.65 -> 放行并执行

          相似度 < 0.65 -> 拒绝, 返回 "声纹验证失败"



  [4] speaker/speaker_verifier.py

      - 新增 verify_any_user(audio_data):

        对所有已注册用户逐一比对, 返回最佳匹配

        返回: (is_verified, matched_user_id, similarity)



  [5] gui.py

      - RecognizeThread.__init__(): 新增 verifier 参数

      - RecognizeThread.run(): 集成验证拦截流程:

      - no_speech_threshold: 0.4 → 0.35（更宽松的语音检测）
      - log_prob_threshold: -1.0 → -0.8（略严格过滤低质量段）

      - 最大录音时长: 10s → 15s（容纳更长的多指令语句）

  [3] audio/audio_preprocess.py (音频预处理)

        按帧计算 RMS，低于最大 RMS 5% 的帧静零处理
